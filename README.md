# SolveAgent

Solve Agent 品牌官网，以 **FixAgent｜Hardware Doctor** 为核心产品，展示从设备照片与状态理解、原因判断、安全测试、反馈复诊，到解决问题或生成完整售后工单的闭环能力。

网站包含动态能力卡片、量子粒子波面和 FixAgent 五步诊断交互演示，并适配桌面、平板与移动端。

## 本地运行

```bash
node server.mjs
```

打开 <http://127.0.0.1:4173>。

也可以使用 `npm run dev`。

## 构建

```bash
npm run build
```

静态产物会输出到 `dist/`。
