# Preserve native Agent tools inside a per-Case sandbox

Customer Mode retains Claude Code's native Bash, Read, Edit, Write, code execution and Skill capabilities so the Agent remains flexible. Each Worker uses its Case Workspace Root, never the FixAgent source root, as `cwd`; native tools can write only to that Case's `scratch/`, while the hash-locked project Skill is exposed through a read-only `.claude/skills/` mount or equivalent mapping, product knowledge and Evidence Packets are read-only, and Case State and Handoff are writable only through MCP. Secret paths are unavailable and Bash has no public network access by default. Runtime should omit a narrow explicit `tools` list; if one is required, it must include `"Skill"`, Bash, Read, Edit, Write and the native tools needed for controlled code execution. The `skills` option selects the concrete Skill but does not replace `"Skill"` in an explicit `tools` list. Knowledge Research Mode may receive a separately approved network policy. Permissions, Hooks and the operating-system sandbox enforce these boundaries without choosing the troubleshooting path for the Agent.
