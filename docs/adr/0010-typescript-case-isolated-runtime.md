# Use one TypeScript Runtime and one Worker per Case

V0 implements only `@anthropic-ai/claude-agent-sdk` in TypeScript; Python is not a second Runtime or acceptance target. Every Case starts a separate Worker process whose `cwd` is that Case's isolated Case Workspace Root rather than the FixAgent source root, with its own Scratch, SDK Session, provider environment and Trace directory. Native tools can write only to `scratch/`; the project Skill is mapped read-only and state-changing writes go through MCP. A Case may resume its own Session, but no process or Session is reused across Cases. When an action requires a later user response, the Agent commits `AWAITING_USER_ACTION`; the Worker saves its Session, releases the Lease and exits, and a new same-Case Worker resumes the same Session and Frozen Provider Profile when the user returns. Waiting does not consume a process or customer round. SDK, provider, tool or storage failure is recorded as `SYSTEM_ERROR`, not a business Outcome. One recovery from the last committed event is allowed under the same Frozen Provider Profile and remains part of the same Run with both traces retained; a second failure terminates the Run and counts against Runtime completion. This narrows the two-person implementation and makes cross-Case isolation and recovery observable without requiring a production container platform.
