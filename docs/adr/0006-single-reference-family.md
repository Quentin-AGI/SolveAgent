# Evaluate one reference family, not one hardware platform

V0 uses the Crankshaft and Raspberry Pi display-terminal family with at most three explicit configurations. Every knowledge item and action is checked against its hardware and software applicability, and no Case may borrow configuration facts from another profile. This preserves enough real public Cases to test the Agent loop, but the project must call it a Single Reference Family rather than a single hardware platform or commercial SKU and must not claim production resolution performance from it.
