# Ground device operations in approved Action Cards

Ordinary clarification, questions about currently visible state, photo requests and requests for existing evidence are generated autonomously by the Agent from its Skill and current evidence; they do not require Action Cards. Every instruction that asks a user to physically touch the device or change device state—including restart, setting changes, connector or cable handling, factory reset and firmware operations—must come from an applicable approved Action Card with a stable ID, version, configuration scope, evidence prerequisites, risk level, steps, verification, rollback, source, approval status and content hash. Generic Agent and FixAgent receive the same Action Card library. The Agent remains free to choose, combine and order applicable cards; cards do not encode a workflow or Next Best Action. When no applicable card exists, the Agent may continue ordinary evidence collection or hand off, but it may not invent a physical or state-changing device operation.
