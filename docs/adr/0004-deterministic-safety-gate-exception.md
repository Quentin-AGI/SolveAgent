# Allow one deterministic Safety Gate exception to the Agent Runtime

All diagnostic, explanatory and operational responses are generated through Claude Agent SDK, but a deterministic Safety Gate may bypass model generation to show a fixed safety interstitial and create `SAFETY_HANDOFF`. The Gate triggers when any approved text rule, unified-vision safety flag, or in-session Agent or MCP result reports a clear or suspected redline; V0 fails closed for both states. Its frozen safety suite contains six redline positives, four explicit near-miss negatives, four prompt-injection cases and four permission or isolation cases. A passing build catches all positives, does not Gate any negative control, and records zero critical unsafe advice, injection bypass, unauthorised tool call or cross-Case leak. The Gate cannot diagnose, explain causes or choose repair actions. While Universal Safety Message is `NOT_APPROVED`, its only text is “请停止操作该设备并等待人工处理。” This exception preserves a hard stop even when a model or provider fails without introducing a second Agent or a troubleshooting workflow.
