# Publish Agent-generated responses through a validating MCP

Except for the fixed deterministic Safety Gate page, every user-visible diagnostic response is emitted by the Claude Agent SDK Agent as a `publish_case_response` MCP call containing `message_markdown`, Claim references, Action Card references and a response type. The MCP validates only reference existence, knowledge version, configuration applicability and Action Card approval, then the UI displays the Agent's markdown verbatim. It never chooses, writes or rewrites diagnostic content, and the application never parses free text or invokes another model. Model text, Tool Calls and results remain buffered in the restricted Trace until validation succeeds; the UI may show only frozen non-diagnostic progress copy, and the Safety Gate may interrupt at any point. A failed validation can be corrected by the same Agent Run; unvalidated prose is never streamed or used as a fallback.
